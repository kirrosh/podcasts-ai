# CLAUDE.md — инструкции для Claude Code в этом репозитории

Этот файл задаёт правила работы Claude в проекте. Он автоматически читается при старте сессии в `/Users/kirrotech/Projects/podcasts-ai`.

## Первое что нужно сделать в любой сессии

1. Прочитать **`PROJECT.md`** — живой файл состояния системы, там актуальные провайдеры, контракты модулей, как запускать, changelog.
2. Прочитать **`config.toml`** — узнать активные провайдеры и стиль по умолчанию.
3. Если запрос связан с генерацией подкаста — прочитать скилл `.claude/skills/podcast/SKILL.md` и следовать его чек-листу.
4. Если запрос связан с wiki/vault — прочитать `vault/CLAUDE.md` (схема wiki).

## Обязательные правила

- **Обновляй PROJECT.md** при любом значимом изменении архитектуры (новый провайдер, смена voice, изменение контракта модуля, новый стиль). Добавляй запись в раздел Changelog.
- **Модульность провайдеров**: никогда не хардкодь Yandex/ElevenLabs/etc вне `podcasts/tts/`, `podcasts/stt/`, `podcasts/stress/`. Оркестраторы работают только с абстракциями.
- **Секреты только в `.env`**: никогда не коммить `.env`, не пиши ключи в конфигах или коде. Смотри `.env.example` для списка переменных.
- **Не использовать `--dangerously-skip-permissions`**.
- **Русские ударения**: при генерации сценариев ставить `+` перед ударной гласной на очевидных омографах (`за+мок`, `пла+чу`, `бе+лки`). RUAccent доберёт остальное, но семантически-обусловленные случаи Claude должен разметить сам.
- **Стиль подкаста — всегда монолог**, без фраз типа "дорогие слушатели", "как мы знаем", "итак". Метафоры и аналогии приоритетнее абстрактных объяснений.

## Команды которые можно безопасно запускать (через Bash)

- `python -m podcasts.build <script.txt>` — сборка mp3 из сценария.
- `python -m podcasts.transcribe <audio.ogg>` — транскрибация голосового.
- `python -m podcasts.ingest <source.epub|.pdf|.txt>` — парсинг источника в vault.
- `sqlite3 state/*.db` — чтение SQLite (если появится).
- `ffmpeg`, `ffprobe` — для отладки аудио.
- `uv sync`, `uv run`, `uv pip install` — управление окружением.

## Что НЕ делать

- Не создавать параллельных bot-сервисов (aiogram и т.п.) — транспорт это Claude Code Channels.
- Не вводить классический RAG с эмбеддингами — работаем через Obsidian LLM Wiki (markdown + wikilinks + Grep).
- Не удалять/перезаписывать файлы в `vault/sources/` и `vault/inbox/` без явного запроса.
- Не коммитить файлы в `audio/`, `vault/sources/`, `vault/inbox/`.
