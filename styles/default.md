# Стиль: Default

Этот файл — индикатор стиля по умолчанию. Реальный стиль определяется полем
`style.default` в `config.toml`. Сейчас это `documentary` — см. `styles/documentary.md`.

При генерации эпизода Claude должен:
1. Прочитать `config.toml` и определить `style.default` (или использовать `--style` из запроса).
2. Прочитать `styles/<имя>.md` и строго следовать ему.
3. Никогда не использовать сам файл `default.md` как инструкцию — это просто указатель.
