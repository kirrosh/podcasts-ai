# vault/CLAUDE.md — схема Obsidian-wiki для podcasts-ai

Это инструкции Claude по поддержанию графа знаний. Структура follows Karpathy's LLM Wiki pattern: сырые источники → сгенерированный wiki → схема.

## Структура vault

```
vault/
├── CLAUDE.md          ← этот файл (схема)
├── sources/           ← сырые первоисточники (epub/pdf/txt), immutable
├── books/             ← per-book обзорные страницы, одна на книгу
├── concepts/          ← LLM-сопровождаемые концептуальные страницы
├── episodes/          ← per-episode метаданные, одна на эпизод
└── inbox/             ← необработанный фидбэк пользователя
```

## Правила именования

- **concepts/**: `Имя Концепта.md` в кириллице, с заглавных букв, пробелы (а не дефисы). Примеры: `Товарный фетишизм.md`, `Прибавочная стоимость.md`, `Отчуждение.md`.
- **books/**: `slug-latin.md` (авто от `python -m podcasts.ingest`). Примеры: `kapital-marks.md`, `republic-plato.md`.
- **episodes/**: `YYYY-MM-DD-slug.md`. Примеры: `2026-04-19-kapital-01.md`.

## Схема страницы концепта

Каждый файл в `concepts/` должен иметь:

```markdown
---
aliases:
  - альтернативное название 1
  - альтернативное название 2
first_mentioned_in: [[2026-04-19-kapital-01]]
related:
  - [[Прибавочная стоимость]]
  - [[Отчуждение]]
---

# Товарный фетишизм

## Определение

Короткое (1-2 предложения) точное определение.

## Контекст

Где и кем введён концепт, в какой работе, какая проблема им решалась (3-5 предложений).

## Углубления

Ключевые нюансы, критика, интерпретации. Каждая подтема — параграф или короткий раздел.

## Связанные концепты

- [[Прибавочная стоимость]] — как связан
- [[Отчуждение]] — как связан

## Упоминания в эпизодах

- [[2026-04-19-kapital-01]] — базовое объяснение через пример витрины
- [[2026-04-22-kapital-02]] — углубление через современные примеры (брендинг)
```

## Схема страницы эпизода

```markdown
---
date: 2026-04-19
topic: Капитал Маркса, том 1, саммари
minutes: 15
style: documentary
script: scripts/2026-04-19-kapital-01.txt
audio: audio/2026-04-19-kapital-01.mp3
concepts_covered:
  - [[Товар]]
  - [[Стоимость]]
  - [[Прибавочная стоимость]]
  - [[Товарный фетишизm]]
book: [[kapital-marks]]
followups_offered:
  - товарный фетишизм с современными примерами
  - разбор главы о прибавочной стоимости
  - критика Бём-Баверка
---

# Капитал Маркса, том 1 — саммари

## О чём эпизод

3-5 буллетов с конкретным содержанием.

## Точки покрытия

Детальный разбор что именно сказано по каждому концепту — нужен для дедупликации в следующих эпизодах.

- [[Товарный фетишизм]]: объяснено через метафору этикетки и витрины; упомянут Marx+Engels; не затронут аспект Альтюссера.
- [[Прибавочная стоимость]]: базовая формула, не углублено про абсолютную/относительную.

## Фидбэк после эпизода

_Автопополняется из `vault/inbox/` при обработке._
```

## Правила поддержания графа

При каждой генерации эпизода Claude **обязан**:

1. **Перед генерацией**:
   - `Grep -r "<тема>" vault/concepts/` → есть ли уже концепт.
   - Если есть — прочитать, понять что уже покрыто, не повторяться, а углублять.
   - `Grep -r "<тема>" vault/episodes/` → какие эпизоды её касались.
2. **После генерации**:
   - Создать новый файл `vault/episodes/YYYY-MM-DD-slug.md` с frontmatter по схеме.
   - Для каждого упомянутого концепта:
     - Если `vault/concepts/<Concept>.md` существует → дополнить разделы «Углубления» и «Упоминания в эпизодах».
     - Если нет → создать заготовку (минимум frontmatter + «Определение»), пополнить в следующих эпизодах.
3. **Кросс-ссылки обязательны**: любое упоминание понятия в тексте концепта/эпизода, которое имеет свою страницу, оформляется как `[[Имя]]`.
4. **Обновление book-страницы**: если эпизод про книгу, обновить её `vault/books/<slug>.md`, добавив эпизод в раздел «Упоминания в эпизодах».

## Антипаттерны (что не делать)

- Не переписывать существующие концепты с нуля — дополнять.
- Не создавать концепты на каждое слово. Концепт = понятие, у которого есть собственная смысловая плотность и которое, вероятно, всплывёт в других эпизодах.
- Не фабриковать связи `[[related]]` — только те, которые реально есть в тексте.
- Не коммитить файлы из `sources/` или `inbox/` в git.
- Не дублировать содержание эпизода в концепт — концепт это синтез по разным эпизодам.

## Лечение графа

При запуске `/lint-wiki` Claude должен:
- Найти битые `[[ссылки]]` (указывают на несуществующие файлы) → либо создать заглушку, либо исправить имя.
- Найти orphan-файлы (на них ничего не ссылается) → оценить нужны ли, пометить `status: orphan` в frontmatter.
- Найти противоречия в описаниях концептов между файлами → залогировать в `vault/inbox/contradictions.md`.
