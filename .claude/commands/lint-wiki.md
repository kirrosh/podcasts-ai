description: Проверить целостность vault — битые ссылки, orphan-страницы, противоречия.
---

Запусти проверку графа заметок:

1. **Битые `[[wikilinks]]`**: через `Grep -rn "\[\[[^\]]+\]\]" vault/` собрать все ссылки, для каждой проверить что существует `vault/concepts/<name>.md`, `vault/episodes/<name>.md` или `vault/books/<name>.md`. Для несуществующих — либо найти опечатку (ближайший существующий файл), либо предложить создать заглушку.

2. **Orphan-страницы**: для каждого файла в `vault/concepts/` проверить, ссылается ли на него хоть один файл (`Grep -l "\[\[<name>\]\]" vault/`). Орфаны не обязательно плохо, но их стоит пересмотреть.

3. **Противоречия**: сравнить определения одного концепта если оно упоминается в разных episode-файлах и в concept-файле — если есть расхождение, залогировать в `vault/inbox/contradictions.md`.

4. **Отсутствующие секции**: каждый `concepts/*.md` должен иметь разделы: «Определение», «Контекст», «Связанные концепты», «Упоминания в эпизодах». Перечислить страницы где секции отсутствуют или пустые.

Отчёт — в Telegram через `reply`: краткая сводка + если есть критичные проблемы, список с путями.
