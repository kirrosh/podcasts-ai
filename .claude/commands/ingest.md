description: Загрузить первоисточник в vault и заполнить обзорную страницу книги.
argument-hint: <путь к файлу .epub|.pdf|.txt> [--title "Название"]
---

Пользователь запрашивает ingest источника: **$ARGUMENTS**

Шаги:

1. Запустить `python -m podcasts.ingest <path>` через Bash — создаст `vault/sources/<slug>.txt` и заготовку `vault/books/<slug>.md`.
2. Прочитать `vault/books/<slug>.md` и извлечённый текст `vault/sources/<slug>.txt` (используй `head` + несколько выборочных кусков — не загружай весь текст в контекст, это может быть длинная книга).
3. Пополнить `vault/books/<slug>.md`:
   - Написать 2-3 абзаца аннотации.
   - Построить оглавление или список ключевых частей (если можешь распознать структуру).
   - Выделить 5-15 **ключевых концептов** — тех, что с высокой вероятностью всплывут в эпизодах. Каждый — `[[Название концепта]]`.
4. Для каждого ключевого концепта, у которого ещё нет страницы в `vault/concepts/`, создать заготовку по схеме из `vault/CLAUDE.md` (минимум frontmatter + краткое «Определение»).
5. Подтвердить пользователю: сколько страниц создано, какие концепты выделены.

Не пытайся генерировать детальные концептуальные страницы за один заход — это задача скилла `wiki-maintainer`, который вызывается при каждом эпизоде. Сейчас цель — заложить якоря.
